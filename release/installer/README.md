# PalCraft installer

Windows PowerShell 5.1 and WinForms; dependencies are installed separately. Run `Install-PalCraft.bat` for the GUI or pass `-Silent`, `-GameDir`, `-MinecraftDir`, `-PackChoice all|hud_skins|islands_animals`, and optional `-MapArt`. `-WhatIf` inventories the same choices without writes. `-LibraryOnly` exposes functions for scratch tests.

The installer selects Minecraft Java 1.21.11, the version validated against the private compatibility tables. It extracts textures/font providers and English language from the jar, Korean language and sounds metadata from the asset index, and the vanilla `data/minecraft/` tree from the jar. A leading `assets/` is stripped; data paths remain under `PalCraft/assets/data/`. Asset-index font providers overwrite jar stubs. No extracted Minecraft content is bundled.

`Build-TextureCache.ps1` builds the local image/font cache. `Initialize-LocalData.ps1` validates required data, creates an index of unchanged extracted JSON documents, and records full jar/index/converter hashes. Runtime `jar_data.lua` generates all 27 tables once, with original PalCraft integration bindings from `data_bindings.lua`, and writes a data-only cache under `PalCraft/cache/`. Subsequent startups read that cache; a changed source identity invalidates it.

The v1.1 candidate enables Minecraft audio on Palworld 1.0.5 Windows. `Patch-CookedPaks.ps1` also invokes `Patch-CookedSounds.ps1`: 360 authored silent SoundWaves in three audio-only paks receive this user's original Vorbis streams. Variable-sized exports and pak indexes are rebuilt deterministically. Supported Minecraft 1.21.11 source hashes, Ogg pages and template hashes are checked; absent or invalid sounds remain valid silence. The local `assets/minecraft/_palcraft/cooked-sound-receipt.json` lists each result and is tracked for uninstall. No Minecraft sound bytes are distributed, and no additional decoder or software is required. Runtime loading is on demand; existing event volume and pitch settings remain in effect.

Payload files live beside this folder under `../payload/<pack>/`, mirroring game-relative paths. Core is mandatory. A CANDIDATE manifest refuses installation before any target write. Enablement follows asset initialization and checked legacy migration. Install receipts record files and hashes; partial install receipts remain available after failure.

For explicitly authorized local acceptance, `-Silent -CandidateTest` permits a CANDIDATE payload without changing its release status. Ordinary installs remain blocked. Uninstall inventories and moves exact PalCraft files, extracted assets, and generated caches into `PalCraft-uninstall-backup/<timestamp>/`; it never recursively deletes a directory. User skins and save sidecars remain unless the documented saves option is selected. The quarantine inventory records every original path and SHA256.

`migrate-legacy.ps1 -LegacyDir <old> -TargetDir <PalCraft> [-GameRoot <game>] [-WhatIf]` copies world-qualified sidecars, recovery `.tmp/.bak/.previous` generations, settings and skins into the new mod root. Different populated destinations stop cutover. With `-GameRoot`, `Cutover-Legacy.ps1` inventories only the exact pak/schema names in `legacy_inventory.json`, moves old loose paks, schema folders and the enabled marker into `PalCraft-legacy-backup/<timestamp>/`, and writes a hash manifest plus `Restore-Legacy.ps1`. Nothing is deleted. Current paks under `~mods/PalCraft/` and unrelated mods stay in place. The installer disables the legacy UE4SS registration after this succeeds.

To reverse cutover, close the game and disable/uninstall the new PalCraft payload first. Run the backup's `Restore-Legacy.ps1 -WhatIf`, then run without `-WhatIf`. Restore checks all hashes and destinations before moving anything, preserves unrelated registrations, and refuses conflicts. Copied PalCraft sidecars remain available. Junctions are rejected in cutover and restore paths.

Offline checks are in `tools/release/test_jar_data.py`, `test_migration.py`, `test_legacy_cutover.py` and `test_legacy_safety.ps1`. The cutover test copies the supplied real layout into evidence and writes only to that scratch copy. Legacy installer tests under `tests/` predate the 1.21.11 data and quarantine contracts; use the current release checks for these gates. Native pack/rig acceptance is separate.

## Robustness on other PCs (v1.0.1 hardening)

Detection: Steam libraries (every `libraryfolders.vdf` entry, spaces and non-ASCII paths, UTF-8 BOM, old and new format; libraries that list app 1623730 first), then Browse. The Xbox/Game Pass edition is refused (exit 5, `game_xbox`). Minecraft: official launcher, CurseForge (`%USERPROFILE%\curseforge\minecraft\Install`), Modrinth App, Prism/PolyMC (`libraries\com\mojang\minecraft`), or any folder passed with `-MinecraftDir`/Browse (an instance folder's `.minecraft` or `minecraft` subfolder is used automatically). Only plain release folders count; Fabric/Forge/OptiFine/snapshot profiles and anything with `inheritsFrom` are ignored. Accepted versions are `$script:SupportedMcVersions` (currently only the validated `1.21.11`; `Initialize-LocalData.ps1` enforces the same). Missing jar, asset index or `ko_kr` asset object stops before any write (exit 3, explanatory message).

Test overrides: `PALCRAFT_STEAM_ROOTS` and `PALCRAFT_MC_ROOTS` (semicolon lists) replace the default detection paths.

Dependencies: UE4SS `Info.json` (tested build `2281fa31`) and PalSchema `dlls\main.dll` FileVersion (minimum `0.6.71`). Missing UE4SS/PalSchema or a PalSchema older than the minimum block the install (exit 2); other UE4SS builds, vanilla UE4SS, newer or unreadable PalSchema only warn. Messages carry the download links.

Install safety: `Assert-InstallPreflight` checks Xbox, dependencies, Minecraft files, write access to the mod and `Pal/Content/Paks` folders (`NOT_WRITABLE`, exit 4), path length (over 259 characters needs Windows long paths, exit 6), and free space (payload + 700 MB, exit 7). Files are copied/extracted to `*.palcraft-tmp` and renamed into place, so a disk-full error (exit 7) never leaves a truncated pak. Read-only files in the target (including `mods.txt`/`mods.json`) are handled. The manifest is checkpointed before each pack copy and after assets, so a failed or killed install is uninstallable; uninstall also sweeps `~mods\PalCraft`, `*.palcraft-tmp`, `config.ini`, `enabled.txt` and `missing-assets.txt`.

GUI: flow layout measured from the text (no clipped Korean/English messages), `&` shown literally, DPI-aware, elevation relaunch passes `-Language` and `-MinecraftDir`. Run `tests\Test-Robustness.ps1` (about 120 checks, writes PNGs to `tests\screenshots\`).
