# PalCraft (한국어)

**v1.0 배포 준비 완료 — Opus 승인 SEQ268.** 두 번째 All 콜드 로딩은 15.702672초(첫 번째 16.002473초)로, 기존 14.5초 목표를 넘었지만 v1.0의 예외로 승인되었습니다. 런타임·설치 프로그램·에셋은 RF에서 실제로 시험한 바이트를 유지합니다.

**팰월드를 마인크래프트 방식으로 즐기세요.** PalCraft는 팰월드 1.0.5용 싱글플레이 모드로, 블록 건축, 도구, 몹, 테마 섬, 마을, 보스와 마인크래프트식 조작·메뉴를 추가합니다. 팰월드 고유의 진행, 생존 규칙, 팰은 그대로 유지됩니다.

[English README](README.md)

> PalCraft를 쓰려면 **본인이 구매한** 마인크래프트 자바 에디션이 필요합니다. 이 모드에는 Mojang이나 Pocketpair의 에셋이 포함되어 있지 않습니다.

## 팩 선택

설치 프로그램에서 세 가지 중 하나를 고릅니다. 어떤 선택이든 작은 **Core**가 항상 함께 설치됩니다.

| 선택 | 내용 |
|---|---|
| **All** | 아래 모두 |
| **HUD & Skins only** | 마인크래프트식 HUD와 화면(인벤토리, 기술, 팰 박스, 팰 도감, 메뉴), 플레이어 스킨(스티브/알렉스, 1인칭·3인칭, 스킨 선택기), 마인크래프트 조작, 블록과 건축, 도구, 무기, 방어구, 활, 겉날개 |
| **Islands & Animals only** | 고속 이동 조각상이 있는 테마 섬 4개, 마인크래프트 몹(팰로 포획 가능), 커스텀 팰 5종, 보스, 평원 마을과 광산. 팰월드 기본 HUD와 조작은 그대로 유지됩니다. |

선택을 바꾸려면 설치 프로그램을 다시 실행하고 게임을 재시작하세요.

## 요구 사항

- 팰월드 **1.0.5** (Windows, 싱글플레이)
- **UE4SS** 팰월드용 실험 빌드, 커밋 `2281fa31`과 호환 ([릴리스](https://github.com/Okaetsu/RE-UE4SS/releases/tag/experimental-palworld))
- **PalSchema** `0.6.71`과 호환 ([릴리스](https://github.com/Okaetsu/PalSchema/releases))
- **마인크래프트 자바 에디션 1.21.11**: 직접 구매하여 설치하고 **한 번 이상 실행**한 상태(공식 런처 또는 CurseForge). PalCraft는 1.21.11 기준으로 검증되었습니다.

UE4SS와 PalSchema는 포함되어 있지 않으니 먼저 설치하세요.

## 설치, 제거, 이전

1. 팰월드를 종료합니다.
2. UE4SS와 PalSchema를 각각의 안내에 따라 설치합니다.
3. PalCraft 릴리스 zip을 풀고 `installer/Install-PalCraft.bat`을 실행합니다.
4. 팰월드 폴더, 마인크래프트 설치 위치(자동 탐색, 찾아보기 가능), 팩 선택을 고릅니다. 설치 프로그램이 본인의 마인크래프트에서 텍스처, 글꼴, 언어, 레시피 데이터를 추출한 뒤 모드를 활성화합니다.
5. 팰월드를 평소처럼 실행합니다. 설치 후 첫 실행에는 일회성 준비로 몇 분이 걸릴 수 있습니다. 이후 로딩은 시험 PC에서 약 15~16초입니다. 설치 중 로컬 텍스처·글꼴 재구성에도 몇 분이 걸립니다.

자세한 내용과 이전 되돌리기는 [INSTALL.md](INSTALL.md)를 보세요.

**제거:** 팰월드를 종료하고 설치 프로그램이 만든 폴더를 삭제하세요: `Mods/NativeMods/UE4SS/Mods/PalCraft/`, `Mods/NativeMods/UE4SS/Mods/PalSchema/mods/` 아래의 `PalCraft_*` 폴더, `Pal/Content/Paks/~mods/PalCraft/`. 팰월드의 월드 저장 데이터는 건드리지 않습니다.

**기존 MinecraftBlocks에서 오셨나요?** 설치 프로그램이 건축물과 설정을 PalCraft로 복사하며(원본은 삭제하지 않음), 이전 pak, 스키마 폴더, 활성화 표시를 `PalCraft-legacy-backup/<타임스탬프>/`로 옮기고 해시 목록과 되돌릴 수 있는 `Restore-Legacy.ps1`을 함께 만듭니다.

## 조작

| 키 | 동작 |
|---|---|
| 좌클릭 (누르고 있기) | 블록 채굴·파괴, 공격, 마인크래프트 도구나 맨손으로 팰월드 바위·나무 채집 |
| 우클릭 | 블록 설치 또는 아이템 사용. 누르고 있으면 활 시위를 당기고, 놓으면 발사 |
| 1-9 / 마우스 휠 | 핫바 |
| Tab | 인벤토리 (팰, 팰 박스, 기술, 팰 도감 탭 포함) |
| E | 파트너 팰 소환/회수 |
| Q | 팰 스피어 던지기 |
| F | NPC와 대화, 고속 이동 조각상 활성화, 탑승/하차 |
| M | 팰월드 지도 (활성화한 조각상 간 고속 이동) |
| Space (공중, 겉날개 착용 시) | 겉날개를 펼쳐 활공 |
| Esc | 게임 메뉴 |

**Islands & Animals only**를 선택하면 팰월드 기본 HUD와 조작이 유지됩니다.

## 주요 기능

- **플레이어:** 마인크래프트식 1인칭/3인칭, 손과 아이템. 스킨 선택기(직접 만든 스킨은 `PalCraft/skins/`에 넣기). 인벤토리에 현재 스킨이 표시됩니다.
- **건축과 아이템:** 블록, 제작, 도구, 검, 방패, 활과 화살(다시 주울 수 있음), 겉날개. 마인크래프트 도구로 팰월드 바위, 팰디움, 나무도 팰월드 도구와 비슷한 속도로 채집합니다.
- **몹:** 바닐라와 같은 모델의 몹 26종(색상 변종, 들고 있는 아이템 포함). 적대 몹은 밤에 나타나 팰과 싸웁니다. 많은 몹을 팰로 포획해 파트너로 쓸 수 있고, 아이언 골렘은 기지를 지킵니다.
- **커스텀 팰:** 균류 숙주(버섯 섬), 아이보리 래틀(사막 섬, 밤), 패치워크 브루트(평원 유적), 레드스톤 레버넌트(정글 신전), 희귀한 모스백. 각자 고유 기술이 있습니다.
- **섬:** 시작 해안 앞 마인크래프트 실제 크기의 섬 4개. 평원(마을, 풍차, 강), 사막(메사, 피라미드, 오아시스), 정글(신전, 폭포 협곡, 밧줄 다리), 버섯(거대 버섯 숲, 동굴). 각 섬에는 팰월드 고속 이동 조각상이 있으며 F로 활성화한 뒤 M 지도에서 이동합니다. 광석 지점은 채굴 후 다시 생깁니다.
- **평원 마을:** **알렉스**(우물 옆)는 블록을 팔고 에메랄드를 하루 최대 8회 교환해 줍니다. **브램**(풍차 대장장이)은 도구를 팝니다. **리나**(농장의 화살 제작자 겸 농부)는 활, 화살, 작물을 팔고 양털·가죽·깃털을 에메랄드로 사 줍니다. 광산에는 석탄, 구리, 철과 보상 상자가 있으며 알파 패치워크 브루트가 지킵니다.
- **보스:** 팰월드의 필드 보스와 같은 방식이며 마인크래프트 공격을 팰월드에 맞게 조정했습니다. 위더(레벨 35, 사막 해안), 워든(레벨 40, 사막 동굴), 엔더 드래곤(레벨 50, 예전 제트라곤 출현 지점). 약화시켜 포획하면 탑승할 수 있습니다. 워든은 걷고 위더와 드래곤은 날며, 카메라는 마우스로 자유롭게 돌고 탑승 능력도 사용할 수 있습니다. 날고 있는 보스에서 공중에서 뛰어내려도 낙하 피해가 없습니다.

## 알려진 제한 사항 (v1)

- 설치 후 첫 실행의 일회성 준비에는 몇 분이 걸리고, 이후 로딩은 시험 PC에서 약 15~16초입니다.
- 비압축 BGRA8 재구성은 이전 BC 압축 화면과 차이가 있으며, 이 화면 차이와 로딩 비용은 승인되었습니다. 기존 아이콘 16개 인스턴스는 오리지널 다각형 디자인 15개로 교체되었습니다.
- 로컬 마인크래프트 입력이 정상 설치에 필요합니다. 패치를 생략하는 진단용 모드에서는 빈 글꼴로 메뉴를 읽을 수 없어 정상 플레이에 적합하지 않습니다.
- Islands & Animals only의 알렉스는 평원 부두 옆 해안에 나타납니다. 외형과 머리 추적은 확인했지만 해당 구성의 거래 상호작용은 입증하지 않았습니다.
- 공개 소스는 허가된 패키지 13,136개를 포함하며, 출처 검토로 텍스처 소스 패키지 5개가 제외되어 완전한 재빌드 키트는 아닙니다. 자세한 기록은 [RELEASE_v1.0.md](RELEASE_v1.0.md)를 보세요.
- **마인크래프트 사운드는 사용할 수 없습니다.** 팰월드 기본 사운드를 쓰거나 무음입니다.
- 비동기 로딩 중 UE4SS 자체의 **드문 크래시**가 발생할 수 있습니다(모드 쪽에서 고칠 수 없음).
- 위더는 체력 절반 이하에서 화살 면역이지만 화살당 1 HP는 들어갑니다.
- 엔더 드래곤의 착지 상태 브레스 공격은 확인되지 않았습니다.
- 300.008초 RF 시험에서 레지스트리는 2,736개 증가했고 힙 범위는 5.229 MB였습니다. 장시간 실행에서 메모리·레지스트리 증가가 제한된다는 보장은 없습니다.
- RF의 5분 시험은 8,999프레임, 최대 45.478601 ms, 60 ms 초과 0회였습니다. 이 수치는 네이티브 월드 델타이며 GPU 화면 표시 시간은 아닙니다.
- 타이틀 화면에 팰월드의 "이전 세션 오류 / 모드" 안내가 뜰 수 있습니다. 그냥 닫으세요.

## 법적 고지

PalCraft는 비공식 팬 프로젝트이며 **Mojang Studios, Microsoft, Pocketpair와 제휴·후원·승인 관계가 없습니다.** Mojang 또는 Pocketpair의 에셋은 배포되지 않습니다. 마인크래프트 텍스처, 사운드, 텍스트는 설치 시 본인의 정식 마인크래프트에서 읽어 오며 PC 밖으로 나가지 않습니다. 모든 상표는 각 소유자에게 있습니다. "Minecraft"라는 이름은 호환성을 설명하는 용도로만 사용됩니다.
